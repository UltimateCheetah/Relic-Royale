# Relic Royale

Relic Royale is an original battle royale prototype inspired by the cadence of modern live-service shooters, but built from scratch with custom names, systems, and lore.

## Included features

- Original menu flow with Play, Modes, Locker, Relics, Relic Pass, Events, Social, Vault, and Settings
- Distinctive social and progression language: Hall, Relic roster, Expedition board, Vault market, and Event board
- Live battle royale match prototype with storm pressure, loot pickups, enemy pressure, and player actions
- Relic system with multiple loadout choices and an energy meter
- End-of-match rewards screen and pass-style progression summary

## How to run

From the project root:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Controls

- W/A/S/D or arrow keys: move
- Mouse: aim
- Click: fire weapon
- Space: trigger current relic ability
- F: fire alternate shot

## Design pillars

- Survival under pressure
- Build-driven power progression
- Tactical ability timing
- Social squad coordination
- High-visibility map exploration

## Note

The project is intentionally original and does not reuse brand names, logos, or direct franchise UI patterns.
